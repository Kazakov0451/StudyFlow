# StudyFlow Frontend

Frontend для приложения StudyFlow — веб-приложения для управления учебными задачами.

## Технологии

- **React** — библиотека для построения пользовательского интерфейса
- **TypeScript** — типизированный JavaScript
- **react-scripts** — сборка и dev-сервер (Create React App)
- **Axios** — HTTP-клиент для взаимодействия с API (заготовка для будущих спринтов)

## Текущий функционал

- 📋 Базовый интерфейс Kanban-доски с тремя колонками: "К выполнению", "В процессе", "Выполнено"
- ⚠️ Заглушка с ошибкой загрузки (API интеграция запланирована в следующем спринте)

## Установка

1. Установите зависимости:
```bash
npm install
```

## Запуск

### Режим разработки
```bash
npm start
```
Приложение откроется на http://localhost:3000

### Продакшен сборка
```bash
npm run build
```
Собранные файлы появятся в папке `build/`.

## Предварительные требования

Бэкенд пока не обязателен для запуска фронтенда. Базовый интерфейс работает с заглушкой.

При запуске бэкенда:
1. Перейди в папку `backend/`
2. Запусти сервер: `uvicorn app.main:app --reload`
3. Бэкенд должен быть доступен на `http://localhost:8000`

## API Endpoints (запланировано)

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/tasks` | Получить список задач |
| GET | `/tasks/{id}` | Получить задачу по ID |
| POST | `/tasks` | Создать новую задачу |
| PUT | `/tasks/{id}` | Обновить задачу |
| DELETE | `/tasks/{id}` | Удалить задачу |
