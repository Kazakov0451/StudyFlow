# StudyFlow Frontend

Frontend для приложения StudyFlow — веб-приложения для управления учебными задачами.

## Технологии

- **React** — библиотека для построения пользовательского интерфейса
- **TypeScript** — типизированный JavaScript
- **react-scripts** — сборка и dev-сервер (Create React App)
- **Axios** — HTTP-клиент для взаимодействия с API
- **@dnd-kit** — библиотека для drag-and-drop функциональности

## Возможности

- 📋 Kanban-доска с тремя колонками: "К выполнению", "В процессе", "Выполнено"
- 🖱️ Drag-and-drop перемещение задач между колонками
- 🔍 Поиск задач по названию и описанию
- 🏷️ Фильтрация по статусу и приоритету
- 📊 Сортировка по дате создания, дедлайну и приоритету
- ⚡ Приоритеты задач: высокий, средний, низкий
- 📈 Статистика и дашборд
- 🌙 Тёмная тема с сохранением в localStorage
- 🔔 Toast-уведомления о действиях
- ⚠️ Подтверждение удаления задач
- 📱 Адаптивный дизайн

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Создайте файл `.env` (опционально):
```bash
cp .env.example .env
```

В файле `.env` можно указать URL бэкенда:
```
REACT_APP_API_URL=http://localhost:8000
```
По умолчанию используется `http://localhost:8000`.

## Запуск

### Режим разработки
```bash
npm start
```
Приложение откроется на http://localhost:3000

### Продакшен сборка
```bash
npm run build
```
Собранные файлы появятся в папке `build/`.

### Запуск тестов
```bash
npm test
```

## Предварительные требования

Перед запуском фронтенда необходимо запустить бэкенд:

1. Перейди в папку `backend/`
2. Запусти сервер: `uvicorn app.main:app --reload`
3. Бэкенд должен быть доступен на `http://localhost:8000`

## API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/tasks` | Получить список задач |
| GET | `/tasks/{id}` | Получить задачу по ID |
| POST | `/tasks` | Создать новую задачу |
| PUT | `/tasks/{id}` | Обновить задачу |
| DELETE | `/tasks/{id}` | Удалить задачу |
