# StudyFlow

StudyFlow — это веб-приложение для студентов, предназначенное для управления учебными задачами, дедлайнами и личным прогрессом.  
Сервис позволяет добавлять задания, отслеживать сроки выполнения, менять статус задач и упрощает планирование учебной деятельности.

## Возможности проекта
- создание и редактирование учебных задач;
- установка дедлайнов;
- изменение статуса выполнения задачи;
- просмотр списка задач;
- фильтрация задач по статусу;
- удобный интерфейс для повседневного использования.
