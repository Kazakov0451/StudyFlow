# Техническое задание
## Проект: StudyFlow

## 1. Общие сведения о проекте

**Название проекта:** StudyFlow

**Тип проекта:** веб-приложение

**Краткое описание:**  
StudyFlow — это веб-приложение для студентов, предназначенное для управления учебными задачами и дедлайнами. Приложение позволяет пользователю создавать задачи, задавать сроки выполнения, отслеживать статус и организовывать учебный процесс более эффективно.

## 2. Цель проекта

Разработать удобное веб-приложение, которое поможет студентам планировать выполнение учебных заданий, контролировать дедлайны и отслеживать прогресс.

## 3. Задачи проекта

1. Разработать интерфейс для работы с учебными задачами.
2. Реализовать создание, редактирование и удаление задач.
3. Реализовать отображение списка задач с дедлайнами и статусами.
4. Реализовать фильтрацию задач по статусу.
5. Обеспечить хранение данных приложения.
6. Создать понятный и удобный пользовательский интерфейс.

## 4. Целевая аудитория

- студенты вузов и колледжей;
- обучающиеся на онлайн-курсах;
- пользователи, которым важно отслеживать учебные дедлайны.

## 5. Проблемы, которые решает приложение

Приложение решает следующие проблемы:
- забывание сроков сдачи заданий;
- отсутствие удобного инструмента для учета учебных задач;
- трудности в планировании учебной нагрузки;
- неудобство использования разрозненных заметок и списков дел.

## 6. Аналоги

Аналогами проекта являются:
- Trello;
- Todoist;
- Notion.

**Отличие проекта:**  
StudyFlow ориентирован именно на учебные задачи и дедлайны студентов, поэтому имеет более простой и специализированный функционал.

## 7. Описание работы приложения

Пользователь открывает веб-приложение и получает возможность:
- создавать задачи;
- указывать название, описание и дедлайн;
- менять статус задачи;
- просматривать список задач;
- фильтровать задачи по статусу;
- редактировать и удалять задачи.
